# Аналізатор часових рядів (Завдання 1 та 2)

Це десктопний додаток на Python (з використанням `tkinter`), призначений для аналізу часових рядів. Програма була розроблена для виконання двох академічних завдань:

1.  **Завдання 1:** Аналіз стаціонарного часового ряду з 16 спостережень.
2.  **Завдання 2:** Демонстрація моделі прогнозування "випадкове блукання з трендом" та розрахунок її похибок.

Додаток має чіткий інтерфейс із двома вкладками, що логічно розділяє ці два завдання, і може завантажувати реальні дані з CSV-файлів.

## 🚀 Можливості

* **Інтерфейс з двома вкладками** для чіткого розділення завдань.
* **Вкладка "Завдання 1"** (аналіз 16 точок):
    * Автоматичне завантаження тестового ряду при старті.
    * Побудова графіка часового ряду (пункт 1а).
    * Побудова діаграми розсіювання `y(t+1)` від `y(t)` (пункт 1в).
    * Розрахунок та відображення коефіцієнта автокореляції `ρ₁` (пункт 1в).
    * Відображення графіка автокореляційної функції (ACF).
* **Вкладка "Завдання 2"** (модель блукання):
    * Завантаження реальних даних з **CSV-файлу** (очікує стовпці `мітка_часу` та `навантаження_мвт`).
    * Побудова прогнозу за моделлю "випадкове блукання з трендом" (пункт 2а).
    * Візуалізація прогнозної похибки (СКП) у вигляді 95% довірчого інтервалу ("конуса").
* **Професійний звіт:**
    * Обидві вкладки мають кнопку "Статистика", яка генерує чистий, структурований звіт (замість консольного виводу).
    * Звіт для Завдання 2 наочно демонструє, як **СКП зростає пропорційно `√τ`** (пункт 2б).

## 🛠️ Встановлення та запуск

### Вимоги

Для роботи проєкту потрібен Python 3.x та декілька бібліотек.

Створіть файл `requirements.txt` та додайте до нього:
```txt
pandas
numpy
matplotlib
```



### Запуск

Для запуску програми виконайте команду:
```bash
python main.py
```

## 🖥️ Як користуватися

1.  **Вкладка 1: Завдання 1 (16 точок)**
    * Дані завантажуються автоматично при запуску.
    * Натискайте кнопки **"Графік ряду (1а)"**, **"Діаграма розсіюв. (1в)"** та **"Статистика (1в)"**, щоб побачити результати аналізу.

2.  **Вкладка 2: Завдання 2 (Модель блукання)**
    * Натисніть кнопку **"📥 Завантажити CSV"**.
    * Оберіть ваш файл з даними (наприклад, `power_load_hourly.csv`).
    * Програма автоматично завантажить дані та побудує графік **"🔮 Прогноз (2а)"**.
    * Натисніть **"📋 Статистика (2б)"**, щоб побачити детальний розрахунок параметрів моделі (`μ`, `σ`) та прогнозних похибок (СКП) для різних горизонтів.

## 📁 Структура файлів

* `main.py`: Головний файл. Створює інтерфейс `tkinter` (вкладки, кнопки), обробляє події та зв'язує все разом.
* `logic.py`: Містить "бек-енд" логіку. Відповідає за завантаження даних (тестових та CSV), всі математичні розрахунки (автокореляція, параметри `μ` та `σ`, генерація прогнозу).
* `plotting.py`: Відповідає за візуалізацію. Містить функції, які створюють `matplotlib` графіки (часовий ряд, діаграма розсіювання, ACF, графік прогнозу).
* `requirements.txt`: Список Python-бібліотек, необхідних для запуску.
* `power_load_hourly.csv`: (Приклад) Файл з даними для тестування Вкладки 2.
